Engine Features

Designed for focus & performance

Built with pure Vanilla JS and browser standard APIs.

Natural Language Parsing

Type Morning run tomorrow @fitness !p1 to parse date, tags, and priority flags dynamically into structured tasks.

Triple Reactive Views

Toggle seamlessly between a status-grouped List, HTML5 native Drag & Drop Kanban Board, and a 7-column Monthly Calendar grid.

Zero-Asset Web Audio Timer

Includes a floating Pomodoro dock that synthesizes pure sine-wave chimes via the Web Audio API without external sound files.

Web Notifications API

Hooks into native browser notification permissions to fire desktop alerts when Pomodoro timers finish or tasks come due.

State Isolation per Account

Ensures multi-tenant data privacy by scoping local storage keys per user ID (e.g. komorebi_tasks_u123).

Zero Emoji Architecture

Strict editorial aesthetic powered exclusively by clean 16x16 vector SVG icons and high-contrast obsidian typography.
